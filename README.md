# Sales-Dashboard

# 📊 Mobile Sales Dashboard - Power BI

## 📌 Overview

The **Mobile Sales Dashboard** is an interactive Power BI project designed to analyze and visualize mobile sales data efficiently. This dashboard provides valuable business insights related to sales performance, customer ratings, payment methods, city-wise sales distribution, and product trends.

The project helps businesses understand customer behavior, identify top-performing products, and monitor overall sales performance using dynamic and interactive visualizations.

---

# 🚀 Features

* Interactive Power BI Dashboard
* Dynamic Filters and Slicers
* Monthly Sales Trend Analysis
* Mobile Model Performance Tracking
* City-wise Sales Analysis
* Customer Rating Insights
* Payment Method Analysis
* KPI-Based Business Reporting


# 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

* Total Sales
* Total Quantity Sold
* Total Transactions
* Average Sales
* Customer Ratings
* Sales Achievement Metrics
